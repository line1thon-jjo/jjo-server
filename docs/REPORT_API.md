# 분석 리포트 API 필드 명세

> 담당: BE2 / 상태: 초안 (실제 녹음 결과를 보며 값만 조정 중)
> 응답 키는 auth·practice API와 같은 snake_case
> 화면 표시 칸의 "시안"은 디자인 시안에 이미 있는 것, "추가"는 시안에 없어서 BE2가 정한 것

## 읽는 법

- **글자 번호**: 본문에서 글자의 위치. 0부터 세고 공백·줄바꿈도 한 글자로 셈. 구간은 시작과 끝 번호를 모두 포함
  - 예: 본문이 "카카오톡은 위챗과"이면 카=0, 카=1, 오=2, 톡=3, 은=4, (공백)=5, 위=6, 3~4 구간 = "톡은"
- **시간**은 밀리초(1000 = 1초). 예: 800 = 0.8초
- 해당하는 것이 없으면 **빈 목록**으로 옴. 필드 자체가 없는 경우는 따로 적음
- 본문은 **말한 내용 기준**. 대본을 그대로 읽었으면 대본과 같고, 바꿔 말하거나 덧붙였으면 그 내용이 반영됨

## 0. 리포트 상태 (모든 화면 공통)

| 필드 | 값 | 의미 | 화면 표시 |
| --- | --- | --- | --- |
| status | PENDING / ANALYZING / COMPLETED / FAILED | 대기 / 분석 중 / 완료 / 실패 | 추가: 분석 중이면 안내 화면, 완료되면 결과 화면 |
| failure.code | 아래 표의 코드 | 실패했을 때만 있음. 코드만 내려주고 문구는 프론트가 정함 | 추가: 코드별 안내 문구 + 다시 녹음 유도 |
| warnings | 아래 표의 코드 목록 (비어 있을 수 있음) | 분석은 성공했지만 알아둘 점 | 추가: 안내 표시 |

status가 PENDING 또는 ANALYZING이면 프론트가 일정 간격(권장 3초)으로 다시 조회하고, COMPLETED 또는 FAILED가 되면 멈춥니다.

실패 코드:

| 코드 | 의미 |
| --- | --- |
| EMPTY_SCRIPT | 대본이 비었거나 너무 짧음 (한글 3글자 미만) |
| AUDIO_NOT_FOUND | 녹음 파일이 없음 |
| AUDIO_DECODE_FAILED | 녹음 파일을 읽을 수 없음 |
| AUDIO_TOO_SHORT | 녹음이 1.5초 미만 |
| AUDIO_TOO_LONG | 녹음이 10분 초과 |
| NO_SPEECH | 말소리가 인식되지 않음 |
| ALIGNMENT_LOW_COVERAGE | 대본과 녹음이 너무 달라 분석 불가 |
| ENGINE_UNAVAILABLE | 분석 엔진 문제 (서버 문제) |
| INTERNAL | 알 수 없는 서버 오류 |

경고 코드:

| 코드 | 의미 |
| --- | --- |
| SCRIPT_DEVIATION | 대본 일치율이 70% 미만 (대본과 많이 다르게 말함) |
| PARTIAL_ALIGNMENT | 대본과 대응된 글자가 85% 미만 (일부만 분석됨) |
| PITCH_UNAVAILABLE | 음높이를 잡지 못함 (높낮이 표시가 없을 수 있음) |

## 1. 헤더와 회차 선택

리포트는 **녹음(회차) 하나당 하나**입니다. 결과 화면은 기본으로 **현재(가장 최근) 녹음**의 리포트를 보여주고, 사용자가 회차를 골라 다른 회차의 리포트를 볼 수 있습니다.

| 필드 | 값 | 예시 | 화면 표시 |
| --- | --- | --- | --- |
| practice_title | 문자열 | "중문이 기말 발표" | 시안: 상단 작은 글씨 "연습 제목 · 시각" |
| recorded_at | 날짜·시각 (ISO 8601, 시간대 포함) | 2026-11-09T03:37:00Z | 시안: 위 줄의 "오늘 12:37". UTC 기준이니 한국 시간으로 바꿔 표시 |
| attempt_no | 1 이상의 정수 | 2 | 시안: "두번째 연습 결과" 큰 제목 |
| duration_ms | 정수, 1500 ~ 600000 | 68000 | 시안: 하단 재생바의 전체 길이 "01:08" |

회차 선택 목록 (`GET /reports/practices/{practice_id}/attempts`, 회차 번호 오름차순):

| 필드 | 값 | 설명 |
| --- | --- | --- |
| attempts[].recording_id | 정수 | 그 회차 녹음의 ID. 리포트 조회 주소에 쓴다 |
| attempts[].attempt_no | 1 이상의 정수 | 회차 번호 |
| attempts[].recorded_at | 날짜·시각 (ISO 8601, 시간대 포함) | 녹음 시각. 예: 2026-11-09T03:37:00Z. UTC 기준이니 한국 시간으로 바꿔 표시 |
| attempts[].status | PENDING / ANALYZING / COMPLETED / FAILED / null | 그 회차의 분석 상태. 분석 중이거나 실패한 회차도 목록에는 나옴. 아직 분석을 시작하지 않은 회차는 null |

- 사용자가 회차를 고르면 그 회차의 recording_id 로 리포트(아래 2~4번 전부)를 새로 조회
- 선택하지 않았을 때의 기본값은 가장 최근 회차

## 2. 전체 결과 탭

| 필드 | 값·범위 | 예시 | 화면 표시 | 없을 때 |
| --- | --- | --- | --- | --- |
| summary.headline | 문자열, 20자 이내 | "호흡은 안정적이었어요." | 시안: 총평 카드 큰 글씨 | 항상 있음 |
| summary.footer | 문자열, 30자 이내 | "후반부 속도와 강조 구절만 다듬어 보세요." | 시안: 총평 카드 작은 글씨 | 항상 있음 |
| speed.fast | 0 이상의 정수 | 4 | 추가: 빠른 구절 수 | - |
| speed.normal | 0 이상의 정수 | 9 | 추가: 보통 구절 수 | - |
| speed.slow | 0 이상의 정수 | 2 | 추가: 느린 구절 수 | - |
| speed.measured | fast+normal+slow와 같음 | 15 | 추가: 구절 수 비율로 표시 (시안의 "평균보다 약간 빠름" 막대를 대체, 표현 방식은 디자인에서 정함) | measured가 0이면 속도 카드를 숨김 |
| habits[].type | 습관 코드 7종 중 하나 (아래 표) | "END_RISE" | 시안: 습관 이름 | 빈 목록이면 "뚜렷한 습관이 발견되지 않았어요" |
| habits[].count | 2 이상의 정수 | 4 | 시안: "4번 발견" 뱃지 | - |

습관 목록은 횟수가 많은 순입니다. 같은 종류가 2번 이상일 때만 나오며, 최대 7개입니다. 시안은 첫 번째를 크게 보여주고 나머지는 "나머지 N개 보기"로 접습니다.

속도 설명 문구(프론트 규칙):
- fast가 slow보다 많으면 "빠르게 지나간 구절이 N곳 있어요" (N = fast)
- slow가 fast보다 많으면 "천천히 말한 구절이 N곳 있어요" (N = slow)
- fast+slow가 measured의 10% 미만이면 "속도가 고르게 유지됐어요"

습관 종류별 이름과 설명 ("끝 올림" 설명만 시안, 나머지 문구는 추가):

| type | 이름 | 설명 |
| --- | --- | --- |
| END_RISE | 끝 올림 | 문장 끝에서 음높이가 올라가는 습관이 나타났어요. |
| END_STRETCH | 끝 끌기 | 문장 끝을 길게 끄는 습관이 나타났어요. |
| END_FADE | 끝 흐림 | 문장 끝에서 목소리가 작아지는 습관이 나타났어요. |
| MID_STRETCH | 중간 늘임 | 문장 중간에서 말을 길게 늘이는 습관이 나타났어요. |
| MID_PAUSE | 중간 쉼 | 문장 중간에서 길게 쉬는 습관이 나타났어요. |
| LONG_PAUSE | 긴 쉼 | 숨 고를 자리에서 평소보다 오래 쉬는 습관이 나타났어요. |
| NO_BREAK | 이어 말하기 | 문장이 끝나도 쉬지 않고 이어 말하는 습관이 나타났어요. |

## 3. 발화 분석 탭

### 3-1. 본문과 글자 모양

| 필드 | 값·범위 | 의미 | 화면 표시 | 없을 때 |
| --- | --- | --- | --- | --- |
| spoken_text | 문자열 | 화면 본문. 모든 글자 번호는 이 문자열 기준 | 시안: 본문 | 항상 있음 |
| marks[].idx | 글자 번호 | 모양을 바꿀 글자 | - | marks가 빈 목록 |
| marks[].pitch | 1, 2, 6, 7 중 하나 | 본인 평균보다 2반음 이상 낮거나(1·2) 높은(6·7) 글자. 1과 7은 4반음 이상 차이. 평범한 글자는 아예 안 내려옴 | 시안: 높게 말한 글자는 위로, 낮게 말한 글자는 아래로 | 이 필드 자체가 없음 |
| marks[].stretch | 2.2 이상의 숫자 (문장 끝 글자는 2.6 이상, 상한 없음) | 본인 평균 길이의 몇 배로 늘였는지 | 시안: 길게 늘인 글자는 가로로 길게 | 이 필드 자체가 없음 |

marks의 한 글자는 pitch와 stretch를 둘 다 가질 수도, 하나만 가질 수도 있습니다.

### 3-2. 속도와 쉼

| 필드 | 값·범위 | 의미 | 화면 표시 | 없을 때 |
| --- | --- | --- | --- | --- |
| paces[].start_idx, end_idx | 글자 번호 | 구절의 시작과 끝 | - | paces가 빈 목록 |
| paces[].label | FAST 또는 SLOW | 본인 평균보다 1.4배 이상 빠름 / 0.7배 이하로 느림. 보통은 내려오지 않음 | 시안: 빠름/느림 구절 표시 | - |
| pauses[].after_idx | 글자 번호 | 이 글자 뒤에서 쉼 | 시안: 글자 사이 간격 | pauses가 빈 목록 |
| pauses[].duration_ms | 400 이상의 정수 (문장 중간 400 이상, 숨 고를 자리는 700 이상이면서 평소의 2배 이상) | 쉰 길이 | 시안: "0.8초"처럼 소수 첫째 자리 | - |

구절은 4글자 이상이고 문장부호와 쉼을 기준으로 나뉩니다. 속도를 못 잰 구절은 paces에 없어서, 구절이 본문 전체를 덮지 않을 수 있습니다.

### 3-3. 대본 일치

| 필드 | 값·범위 | 의미 | 화면 표시 | 없을 때 |
| --- | --- | --- | --- | --- |
| replaced[].start_idx, end_idx | 글자 번호 | 대본과 다르게 말한 곳의 위치 (본문에 이미 말한 내용으로 반영됨) | 추가: 다르게 말함 표시 | 빈 목록 (대본대로 읽으면 대부분 비어 있음) |
| replaced[].spoken | 문자열, 3글자 이상 | 말한 단어 | 추가: 위와 같음 | - |
| replaced[].script_text | 문자열 | 원래 대본의 해당 부분 | 추가: 원래 대본 표시 | - |
| added[].start_idx, end_idx | 글자 번호 | 덧붙여 말한 곳 (본문에 포함됨) | 추가: 덧붙임 표시 | 빈 목록 |
| added[].spoken | 문자열, 3글자 이상 | 덧붙인 말 | - | - |
| skipped[].start_idx, end_idx | 글자 번호, 연속 2글자 이상 | 말하지 않고 건너뛴 곳 (본문에 대본 글자가 그대로 남아 있음) | 추가: 건너뜀 표시 | 빈 목록 |

범례: 시안에는 빠름/느림/쉼 3가지가 있음

### 3-4. 구절 클릭 재생

| 필드 | 값·범위 | 의미 | 화면 표시 |
| --- | --- | --- | --- |
| segments[].start_idx, end_idx | 글자 번호 | 구절의 위치. 본문 전체를 빈틈없이 나눔 | 추가: 구절을 누르면 해당 구간 재생 |
| segments[].start_ms, end_ms | 정수 (밀리초) | 구절의 재생 시작·끝 시각 | - |

재생바: 시안에 하단 고정 재생바(재생 버튼, 현재 시각, 진행바, 전체 길이)가 있음

### 응답 예시

```json
{
  "spoken_text": "카카오톡은 위챗과 마찬가지로 ...",
  "marks":    [{ "idx": 12, "pitch": 7, "stretch": 2.8 }, { "idx": 30, "pitch": 1 }],
  "paces":    [{ "start_idx": 30, "end_idx": 52, "label": "FAST" }],
  "pauses":   [{ "after_idx": 80, "duration_ms": 800 }],
  "segments": [{ "start_idx": 0, "end_idx": 20, "start_ms": 400, "end_ms": 4100 }],
  "replaced": [{ "start_idx": 100, "end_idx": 106, "spoken": "프레젠테이션을", "script_text": "발표를" }],
  "added":    [{ "start_idx": 120, "end_idx": 130, "spoken": "정말 열심히" }],
  "skipped":  [{ "start_idx": 140, "end_idx": 142 }]
}
```

## 4. AI 피드백 탭

| 필드 | 값·범위 | 예시 | 화면 표시 | 없을 때 |
| --- | --- | --- | --- | --- |
| items | 최대 3개 | - | 시안: 탭 옆 뱃지(3) | 빈 목록이면 "이번에는 연습할 점이 없어요" |
| items[].rank | 1, 2, 3 | 1 | 시안: 번호(01~03), 1번은 "우선 연습" 강조 라벨, 2·3번은 "다음 연습" | - |
| items[].title | 문자열, 20자 이내 | "핵심 이유를 천천히 강조하기" | 시안: 굵은 제목 | - |
| items[].quote | 문자열, 40자 이내 (길면 앞부분만) | "가장 큰 이유인 사회문화적 차이입니다." | 시안: 따옴표로 감싼 인용 구절 | - |
| items[].body | 문자열, 90자 이내 | "가장 중요한 구절인데 평소보다 빠르게 지나갔어요. …" | 시안: 설명 문장 | - |
| items[].start_ms, end_ms | 정수 (밀리초) | 27300, 31800 | 시안: "해당 부분 듣기" 버튼으로 구간 재생 | - |
| items[].start_idx, end_idx | 글자 번호 | 150, 172 | 추가: 내부 연결용 (본문 위치) | - |
| items[].kind | 습관 코드 7종 / PACE / PAUSE | "PACE" | 추가: 내부 연결용 (어떤 분석에서 나온 피드백인지) | - |

시안: 항목마다 우측에 접기 화살표, 화면 상단 "다음 연습에서 신경쓸 3가지 / 한 가지씩 차근차근 연습해 보세요.", 하단 "다시 연습하기" 박스

## 5. 재생

| 필드 | 값 | 설명 |
| --- | --- | --- |
| audio_url | 주소 문자열 | 녹음 재생 주소. 구간 이동(Range) 지원 |
| expires_in_seconds | 1800 | 30분간 유효 |

- 30분이 지나 재생이 실패하면 프론트가 새 주소를 요청해서 이어 재생
- 구간 재생은 segments와 items의 start_ms, end_ms를 사용

## 6. 유의

- marks의 음높이 기준(2반음)과 구절·습관 임계값은 실제 녹음 결과를 보며 값만 조정함. 필드 구조는 그대로
- BE3가 정확도를 계속 개선 중이라 판정 결과가 달라질 수 있음
- 회차 사이 비교 수치는 현재 제공하지 않음 (추후 추가)
- 글자 수 상한(총평, 피드백 제목·설명 등)은 시안 길이 기준이며 Gemini 프롬프트에 반영 예정
