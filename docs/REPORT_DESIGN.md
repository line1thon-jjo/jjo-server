# 분석 결과 화면: 디자이너용 데이터 안내

> 개발 명세는 `REPORT_API.md`에 있고, 이 문서는 "화면에 어떤 정보가 어떤 형태로 오는지"만 설명합니다
> "시안"은 디자인 시안에 이미 있는 것, "추가"는 시안에 없어서 새로 디자인이 필요한 것

## 먼저 알아둘 것

**새로 디자인이 필요한 것**
1. 대본 일치 표시 3종(다르게 말함 / 덧붙임 / 건너뜀)
2. 분석 중 화면
3. 분석 실패 화면 (사유별 문구)
4. 분석 경고 안내
5. 회차 선택 (회차마다 분석 상태 표시 포함)
6. 구절을 눌러 재생할 때의 상태 표시
7. 빈 상태 (습관 없음, 피드백 없음, 속도 카드 숨김)

**용어**
- **본인 평균**: 그 녹음 안에서 사용자 본인의 평균입니다. 다른 사람이나 일반 기준과 비교하는 게 아닙니다.
- **구절**: 문장부호나 쉼으로 끊은 덩어리입니다. 문장보다 작을 수 있고, 4글자 이상입니다.
- **반음**: 피아노 건반 한 칸 높이 차이입니다.

**주의**: 글자 모양이 몇 개쯤 나오는지는 실제 녹음으로 확인 중입니다. 값의 기준은 조정될 수 있지만 화면 구조는 바뀌지 않습니다.

## 1. 헤더와 회차

- 보이는 것: 연습 제목, 녹음 시각, 회차 번호("두번째 연습 결과"), 재생바 전체 길이
- 결과 화면은 기본으로 **현재(가장 최근) 녹음**이고, 사용자가 회차를 골라 다른 회차 결과를 볼 수 있음
- 회차마다 분석 상태가 있음: 대기 / 분석 중 / 완료 / 실패 (분석 중이거나 실패한 회차도 목록에는 나옴)
- 녹음 길이: 1.5초 ~ 10분

## 2. 전체 결과 탭

**총평 (시안)**
- 두 줄입니다. 첫 줄은 20자 이내, 둘째 줄은 30자 이내입니다.
- AI가 쓴 문장이고 항상 있습니다.
- 예: "호흡은 안정적이었어요." / "후반부 속도와 강조 구절만 다듬어 보세요."

**전체 말하기 속도 (추가: 시안의 "평균보다 약간 빠름" 막대를 대체)**
- 속도를 잰 구절을 빠름 / 보통 / 느림으로 나눈 **개수 비율**이 옵니다. 표현 방식은 디자인에서 정합니다.
- 설명 문구는 셋 중 하나입니다.
  - 빠른 구절이 더 많으면 "빠르게 지나간 구절이 N곳 있어요"
  - 느린 구절이 더 많으면 "천천히 말한 구절이 N곳 있어요"
  - 빠르거나 느린 구절이 전체의 10% 미만이면 "속도가 고르게 유지됐어요"
- 속도를 잰 구절이 하나도 없으면 이 카드를 숨깁니다.

**발견한 습관 (시안)**
- 0개~7개이고 횟수가 많은 순입니다. 같은 종류가 2번 이상 나와야 습관으로 칩니다.
- 항목마다 이름, "N번 발견", 한 줄 설명이 있습니다.
- 시안은 첫 번째를 크게 보여주고 나머지는 "나머지 N개 보기"로 접습니다.
- 0개이면 "뚜렷한 습관이 발견되지 않았어요" (추가)

| 이름 | 설명 |
| --- | --- |
| 끝 올림 | 문장 끝에서 음높이가 올라가는 습관이 나타났어요. (시안) |
| 끝 끌기 | 문장 끝을 길게 끄는 습관이 나타났어요. |
| 끝 흐림 | 문장 끝에서 목소리가 작아지는 습관이 나타났어요. |
| 중간 늘임 | 문장 중간에서 말을 길게 늘이는 습관이 나타났어요. |
| 중간 쉼 | 문장 중간에서 길게 쉬는 습관이 나타났어요. |
| 긴 쉼 | 숨 고를 자리에서 평소보다 오래 쉬는 습관이 나타났어요. |
| 이어 말하기 | 문장이 끝나도 쉬지 않고 이어 말하는 습관이 나타났어요. |

## 3. 발화 분석 탭

**본문 (시안)**
- 사용자가 **말한 내용 기준**의 글입니다. 대본을 그대로 읽었으면 대본과 같고, 바꿔 말하거나 덧붙였으면 그 내용이 들어갑니다.
- 대본의 줄바꿈이 유지될 수 있습니다.

**글자 모양 (시안)**
- 눈에 띄는 글자만 모양이 바뀝니다. 평범한 글자는 그대로입니다.
- **높낮이**는 네 단계입니다. 위로는 "높음"과 "아주 높음", 아래로는 "낮음"과 "아주 낮음"입니다. 본인 평균보다 2반음 이상 차이 나는 글자만 해당하고, 아주 높거나 낮음은 4반음 이상입니다.
- **늘임**은 평소 글자 길이의 2.2배 이상(문장 끝 글자는 2.6배 이상)일 때입니다. 상한이 없어서 4배 이상도 나올 수 있으니 최대 길이를 정해야 합니다.
- 한 글자가 높낮이와 늘임을 둘 다 가질 수 있습니다.

**빠름/느림 구절 표시 (시안)**
- 구절 단위입니다. 빠름과 느림 두 가지만 있고 보통은 표시가 없습니다.
- 속도를 못 잰 구절에는 표시가 없어서 본문 전체를 덮지 않을 수 있습니다.
- 구절은 문장보다 작거나 문장 하나일 수 있고, 여러 줄에 걸칠 수 있습니다.

**쉼 (시안)**
- 쉰 위치와 길이가 옵니다. 길이는 "0.8초"처럼 소수 첫째 자리로 표기합니다(시안).
- 문장 중간에서 0.4초 이상 쉰 곳과, 숨 고를 자리에서 0.7초 이상(평소의 2배 이상) 쉰 곳만 나옵니다.
- 실제 녹음(99.8초)에서는 약 10개가 나왔습니다.

**대본 일치 (추가)**

| 종류 | 의미 | 함께 오는 정보 |
| --- | --- | --- |
| 다르게 말함 | 대본과 다른 단어를 말함. 말한 단어는 3글자 이상 | 말한 단어, 원래 대본 |
| 덧붙임 | 대본에 없는 말을 덧붙임. 3글자 이상 | 덧붙인 말 |
| 건너뜀 | 말하지 않고 넘어감. 연속 2글자 이상 | 본문에는 대본 글자가 그대로 남아 있음 |

- 대본대로 읽으면 대부분 비어 있습니다. 실제 녹음 한 건에서는 "다르게 말함"이 1건이었습니다.
- 표시 방식은 디자인에서 정합니다.

**겹침 (추가)**
한 글자에 글자 모양, 밑줄, 대본 일치 표시가 동시에 걸릴 수 있습니다. 어느 표시가 우선인지 정해야 합니다. 건너뜀 글자는 소리가 없어서 모양이 붙지 않습니다.

**구절 클릭 재생 (추가)**
- 본문 전체가 구절로 빈틈없이 나뉩니다. 구절을 누르면 그 구간이 재생됩니다.
- 재생 중인 구절을 어떻게 표시할지 디자인이 필요합니다.

**범례와 재생바 (시안)**
- 범례: 빠름 / 느림 / 쉼
- 하단 재생바: 재생 버튼, 현재 시각, 진행바, 전체 길이

## 4. AI 피드백 탭

- 항목은 최대 3개이고 탭 옆 뱃지에 개수가 표시됩니다(시안).
- 항목마다 아래가 있습니다.
  - 순위: 01~03. 1번은 "우선 연습" 강조 라벨, 2·3번은 "다음 연습" (시안)
  - 제목: 20자 이내 (시안)
  - 인용 구절: 40자 이내. 길면 앞부분만 (시안)
  - 설명: 90자 이내 (시안)
  - "해당 부분 듣기" 버튼: 누르면 그 구절을 재생 (시안)
- 항목이 하나도 없으면 "이번에는 연습할 점이 없어요" (추가)

## 5. 분석 상태, 실패, 경고 (추가)

**분석 중**
- 결과 화면을 열었을 때 아직 분석 중일 수 있습니다. 안내 화면이 필요하고, 완료되면 자동으로 결과로 바뀝니다.

**실패** (사유별 문구가 필요합니다)

| 상황 | 설명 |
| --- | --- |
| 녹음이 너무 짧음 | 1.5초 미만 |
| 녹음이 너무 김 | 10분 초과 |
| 말소리가 없음 | 말소리를 인식하지 못함 |
| 녹음 파일을 읽을 수 없음 | 파일이 없거나 열 수 없음 |
| 대본과 너무 다름 | 대본과 녹음이 너무 달라 분석 불가 |
| 대본이 너무 짧음 | 한글 3글자 미만 |
| 서버 문제 | 분석 엔진 문제 또는 알 수 없는 오류 |

**경고** (분석은 성공했지만 사용자가 알아두면 좋은 점)

| 상황 | 설명 |
| --- | --- |
| 대본과 많이 다르게 말함 | 대본 일치율 70% 미만 |
| 일부만 분석됨 | 대본과 대응된 글자가 85% 미만 |
| 높낮이를 잡지 못함 | 글자 높낮이 표시가 없을 수 있음 |

## 6. 아직 모르는 것

- 글자 모양이 한 화면에 몇 개쯤 나오는지: 실제 녹음으로 확인 중이며, 너무 많으면 기준을 올려 줄임
- 값의 기준은 조정될 수 있으나 화면 구조는 그대로
- 회차 사이 비교 수치는 현재 제공하지 않음 (추후 추가)
